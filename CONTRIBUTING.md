# Contributing to Netflix EDA Project

Thank you for your interest in contributing! If you have suggestions, bug fixes, or improvements for this exploratory data analysis, here is how you can help:

1. **Open an Issue:** If you find a bug or have a suggestion, open an issue first to discuss what you would like to change.
2. **Submit a Pull Request:** Fork the repository, make your changes on a separate branch, and submit a pull request for review.
